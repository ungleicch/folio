# Folio

A personal library in a quiet Mac style. Books sit on 3D shelves. Click a spine to pull it out, rate it, and keep a note on how it felt. Your library stays in this browser.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:8080.

- **Add book** searches Open Library, or you can type a book in yourself.
- **Cards** and **List** are there if you do not want the 3D view.
- **Insights** tracks a yearly reading goal.
- Export or import the library as JSON from the download menu.
- Sample books are only there so the shelves are not empty. Clear them when you are ready.

No account is required. Nothing is sent to a database.
